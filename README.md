# Ashiana Amodh - Senior Living Website

A modern, responsive website for Ashiana Amodh, a senior living project in Talegaon, Pune.

## Features

- Responsive design for all devices
- Image gallery with lightbox
- Video integration
- Contact form with EmailJS
- Age-friendly amenities showcase
- Project details and legal documents
- Testimonials and awards section

## Setup & Deployment

### GitHub Pages Deployment

1. Go to your repository settings on GitHub
2. Navigate to **Pages** in the left sidebar
3. Under **Source**, select **Deploy from a branch**
4. Choose **main** branch and **/ (root)** folder
5. Click **Save**
6. Your site will be live at: `https://abhi5400.github.io/ashina_amodh/`

### Local Development

Simply open `index.html` in a web browser or use a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (http-server)
npx http-server
```
